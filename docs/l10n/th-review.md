# Thai review: start here

PaiSeN has Thai for every screen. There is no Thai design, so a native Thai reader checks all of it
before Thai is offered in release builds. Until then only debug builds show it.

## How to check

1. Install the debug build. On a phone set to Thai it opens in Thai. On any other phone, pick ไทย in
   Settings → Language.
2. Read the tables below in this order, with the app open beside them. Each row gives the English,
   the Thai and the field in the code.
3. Write fixes straight into the Thai column, or add a note under the row. Mark a row you are unsure
   about with `?`.
4. When every table is done, add your name and the date under Sign-off.

| Order | Table | What it covers | Rows |
|---|---|---|---|
| 1 | [th-shell.md](th-shell.md) | Words every screen shares, the tab bar, dates, the Language screen, phrases | 134 |
| 2 | [th-today-add.md](th-today-add.md) | Today, the weekly recap and weekly target, the Add sheet and the mic, the day receipt | 99 |
| 3 | [th-slips-setup.md](th-slips-setup.md) | To check, Check slip, shop rules, Activity, Photo folders, first run | 146 |

## Decide these first

Each one repeats across many rows, so a change here is one change in many places.

| Choice | Now | Table |
|---|---|---|
| Tone | Neutral polite, no ครับ or ค่ะ; the reader is คุณ | all |
| Save and note | Save is บันทึก, a note is โน้ต | `th-shell.md` |
| Shared tab and a shared group | กลุ่ม | `th-shell.md`, `th-shared.md` |
| Remove and delete | Remove is นำ…ออก (can come back), delete is ลบ | `th-shared.md` |
| Settle up | เคลียร์ยอด, or ชำระยอด? | `th-shared.md` |
| Repeats | รายการประจำ | `th-slips-setup.md`, `th-shared.md` |
| Years and digits | Buddhist Era (2569), digits 0–9 | `th-shell.md` |
| Left in English on purpose | Reports tabs W M 3M 6M Y, the year chart's month letters | `th-browse.md` |

## Look for on the phone

- Words cut off or wrapped in small fixed places: the tab bar, Today's Week and Month tabs,
  segmented buttons, chips, the Pay me card, Who pays whom rows.
- Tone marks or vowels clipped at the top or bottom of a line.
- A line that breaks inside a word.
